#  Autonomous Local Dockerfile Generator

An autonomous, privacy-focused DevOps CLI tool that analyzes project source repositories, generates production-ready `Dockerfile` configurations using local open-weight Large Language Models (LLMs), and automatically self-heals build errors via a deterministic Docker CLI feedback loop—running **100% locally with zero cloud API costs**.

---

##  Key Features

****-  100% Local & Privacy-Preserving:** Uses locally hosted open-weight models (`Qwen 2.5 Coder 1.5B`) via Ollama. No source code or credentials ever leave your * **100% Local & Privacy-Preserving:** Uses locally hosted open-weight models (`Qwen 2.5 Coder 1.5B`) via Ollama. No source code or credentials ever leave your machine.
* **Dynamic Context Scanning:** Reads project manifests (`requirements.txt`, `package.json`, `go.mod`, `pom.xml`) to understand dependencies automatically.
* **Agentic Self-Healing Loop:** Automatically captures `stderr` output from failed `docker build` attempts and feeds logs back to the LLM for inline repair (up to 3 retries).
* **Resource Optimized:** Tuned with 4-bit quantization (`Q4_K_M`) to run smoothly on 8 GB RAM machines with integrated graphics.
* **Cross-Platform Stream Safety:** Explicit UTF-8 stream handling prevents cross-platform encoding exceptions on Windows PowerShell and Linux terminals.

##  Prerequisites

Before running the project, ensure you have the following installed:

1. **[Ollama](https://ollama.com/)** (Local LLM runner)
2. **[Docker Desktop](https://www.docker.com/products/docker-desktop/)** (Must be active and running)
3. **[Python 3.10+](https://www.python.org/)**

##  Quickstart Guide

### 1. Clone the Repository
```bash
git clone https://github.com/your-username/dockerfile-generator.git
cd dockerfile-generator
```

### 2. Set Up Virtual Environment
```bash
# Create virtual environment
python -m venv venv

# Activate (Windows PowerShell)
.\venv\Scripts\Activate.ps1

# Activate (Linux/macOS)
source venv/bin/activate

# Install required dependencies
pip install ollama
```

### 3. Pull the Lightweight Code Model
Download the 4-bit quantized code model (consumes ~1.2 GB RAM):
```bash
ollama pull qwen2.5-coder:1.5b
```

### 4. Run the Generator
Ensure Docker Desktop is running, then execute:
```bash
python main.py
```

##  Testing Across Tech Stacks

To test the generator on different tech stacks, place a standard project manifest in the project root directory:

- **Python:** Include a `requirements.txt` file.
- **Node.js:** Include a `package.json` file.
- **Go:** Include a `go.mod` file.
- **Java:** Include a `pom.xml` file.
